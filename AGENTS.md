# Project: Filinvest Commercial Lots Properties Explorer

Interactive kiosk/web app for browsing Filinvest commercial lots across four townships:
Filinvest City (Alabang), City di Mare (Cebu), Daang Hari (Las Piñas), and
Brentville – The Village Front (Biñan, Laguna).

## Stack
- React 19 + TypeScript, built with Vite 6
- Tailwind CSS v4 (`@tailwindcss/vite`), Motion + anime.js for animation
- Leaflet / React Leaflet (OpenStreetMap) with Geoman for lot-boundary editing
- Fonts bundled locally via `@fontsource` (Inter, Montserrat) — the app must keep working offline

## Screen flow
`LandingScreen` → `LoadingScreen` → `SelectionScreen` (pick a township) → `ViewerScreen`
(map / concept-map view via `InteractiveSDP`, lot details, `InquiryModal` / `LeadCaptureForm`).
An inactivity timeout (`useInactivityTimeout`) returns the kiosk to the landing screen.

## Data
- Projects and lots live in `src/constants.ts` (`COMMERCIAL_PROJECTS`, `COMMERCIAL_LOTS`).
- Lot polygons are overridden at load time from `src/lotCoordinates.json` (lat/lng) and
  `src/conceptCoordinates.json` (SVG points on the concept map).
- In dev only, `vite.config.ts` exposes `POST /api/save-lots` and `POST /api/save-concept-lots`,
  which write edited polygons back to those JSON files. These endpoints do not exist in production.
- Lot `status` is `Available | Reserved | Sold`. Only `Sold` is rendered on the maps (grey via
  `getLotColor`, "SOLD" label) and it blocks lot inquiries. To mark a lot sold, set its status in
  `src/constants.ts` (Daang Hari uses a `sold: true` flag in its lot table).
- Township categories (`TownshipBrand`): Premier Township, Coastal Hub, High Growth Area,
  Exurban Community — colours in `BRAND_COLORS_COMMERCIAL`.

## Assets
- Static assets live in `public/` (per-township folders `FC/`, `CDM/`, `DH/`, `TVF/`).
- Keep photos web-sized (≤ 2560 px on the long edge, JPEG ~q82) before committing.
- `public/tiles/` is generated by `npm run download-tiles` and is git-ignored.
